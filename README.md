## 🔧 安装指南
### 环境要求
- Node.js ≥ 18

### 安装步骤
1. 克隆仓库：
   ```bash
   git clone https://github.com/YeXingKe/home.git
   ```
2. 安装依赖：
   ```bash
   cd home
   pnpm i
   ```
